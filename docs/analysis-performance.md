# 多変量分析の高速化（v1.5.31）

2・3・4要素の8種類の非線形モデル、探索する変数・周波数・形状候補、2巡の探索、標本数、検証用の分割、採用条件を維持して計算を軽量化します。

## 計算の共通化

- 説明変数の変換、中心化・尺度調整、行列の積和を、同じ学習データの探索中で共有します。倍精度の数値配列を使用し、行ごとの一時配列を減らします。
- 3・4要素の形状を1変数ずつ変更する際は、固定された説明変数の影響を一度除去し、変わる1・2・4列のみを解きます（Frisch–Waugh–Lovellの分割回帰）。最終モデルの係数は全説明変数を使って推定します。
- 定数・特異行列・非有限な基底、ほぼ従属した変換、完全な適合や採用境界の近傍では、全行列の回帰または残差の直接計算で確認します。
- 学習・検証の基準を満たさないモデルは、その時点で終了します。採用の可能性があるモデルについて全体R²と各変数の寄与を評価します。

## 設定変更時の再利用

分類手法・群数・分類指標・期間・DBSCAN設定などだけを変更する際は、数値列の集計と相関・線形／非線形の探索結果をメモリから再利用します。主成分と群の割当・中心・比較結果は現在の設定で再計算します。結果の「処理」欄に再利用を記録し、MD／XLSXにも含めます。

入力表全体と数値計算の設定を照合するため、値・見出し・対象行列・入力表へ反映された表示条件・対象列・合流条件・非線形モデルが変われば再計算します。CPUのみ／GPU優先／バランスの切替も区別します。ファイルを閉じる、全処理を取り消す、アプリを終了する際は保存した結果を破棄します。設定変更による古い要求の取り消しは、完了済みの結果を破棄しません。

保存量は分析メモリ予算の10%以内、最大128 MB・64件です。シリアライズしたサイズの4倍と管理領域を予約量の見積もりとし、古い結果から削除します。実行中の分析に必要な予約量を優先し、メモリに余裕がなければ再利用を省きます。保存はメモリ内だけで、ディスクや外部サービスへ書き出しません。

## 同じデータでの測定

2026年10月13日、Linux・Node.js 24.19.0・AMD EPYC 9V74、CPUのみ／1分析ワーカーで測定しました。二次の交互作用・周期・指数を含む固定シードの6変量180行を使用し、3回の中央値です。ファイル読込と画面の描画時間は含まず、ワーカーの起動・転送・結果の受け取りを含みます。

| 操作 | v1.5.30 | v1.5.31 |
| --- | ---: | ---: |
| 初回の全モデル分析 | 37.013秒 | 3.323秒 |
| 群数3→4の変更 | 37.182秒 | 0.039秒 |

この比較で初回は約11.1倍、群数変更は約943倍となりました。保存した結果の見積もりは約0.98 MBです。検出した非線形の8候補の方向・モデル・検証R²（許容差1e-8）、全13件の多要素候補と2変量15組を確認しています。実データの列数、欠損、シート数、分類法、CPU／GPUや他のアプリの負荷により速度は変わります。

再現用コマンド：`node scripts/benchmark-analysis.cjs --runs=3`。雑音・線形は `--case=noise`／`--case=linear`、行数は `--rows=5000`、比較する旧版のelectronディレクトリは `--engine=/path/to/electron` で指定できます。合成データを用い、ユーザーのファイルは読みません。
